# 📚 Basis Data Semester 2

Repositori ini berisi dokumentasi materi perkuliahan dan skema database praktikum untuk mempermudah teman-teman angkatan belajar dan mengerjakan tugas.

## 📂 Struktur Repositori
- `/materi_markdown`: Rangkuman materi perkuliahan (Konsep DB, DDL, DML, ERD).
- `/src_sql`: Kumpulan mentahan skema tabel dan data *dummy* untuk latihan.

## 🚀 Cara Menggunakan Skema SQL
Bagi yang ingin langsung mencoba di *local* masing-masing tanpa harus *copy-paste* baris per baris:
1. Pastikan Apache dan MySQL di XAMPP sudah menyala.
2. Buka command prompt / terminal, masuk ke MySQL:
   `mysql -u root -p`
3. Eksekusi file SQL:
   `source src_sql/kumpulan_skema_latihan.sql`
